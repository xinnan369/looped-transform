### Execution and output

Run the frozen [WSL entry point](../../scripts/run_lc007h_e40.sh) after the diagnostic review and owner-approved scope are recorded. The driver compares the authorization record with the running clean commit, exact config digest, read-only scope and budget. A per-image time guard reserves cleanup, and the launcher sends TERM at 295 s with a 5 s hard-kill allowance. A parity error, unscorable position, actual OOM or time failure stops the run and retains any completed records. A missing or incomplete summary represents a blocked case even if image rows exist.

The root `progress.json` records status, completed cases, current case, device headroom and observed peak memory. `gpu_phases.jsonl` contains charge and failure per phase. Each case directory contains `images.jsonl` with ordered per-image stage count rows, GT/candidate identities, midpoint ambiguity bins, transition details, and the hypothetical aligned/permuted gain spread, correlation and changed count. The case `summary.json` includes image and group parity, threshold AP, bin numerators, denominators and rates, the count of unscorable GT, hashes and invariant checks. Empty denominators yield null rates. High-confidence FP means candidate score ≥.75. These measured gain statistics would describe the maps of the frozen controls. Training-specific placebo behavior requires measurement in the trained arms.
