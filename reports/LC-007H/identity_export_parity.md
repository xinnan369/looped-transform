# Opt-in identity export and matching

Existing inference returns the same candidate coordinates, scores, tile ownership and ordering. The opt-in flag `export_identity=True` additionally attaches `(tile, row, column, slot)` in the original decode order. AP reads all valid in-frame candidates over the configured floor >.05. Count reads only the unique ownership region with score >.30 and matches at δ=.50. The identity path calls the same stable score-ranked matcher, preserving the original column and match order on ties. GT IDs are annotation rows within each image.

An FN is any GT row left unmatched, including heads with no candidate in their neighborhood. An unmatched count candidate is a duplicate if it lies strictly within .50 times local GT spacing of a GT with an assigned candidate. It is background if it lies outside all such GT radii. The defensive `unassigned_near_gt` category records an eligible unmatched neighbor when no nearby GT has an assignment. Classification never changes matching or the FP total.

Stage transitions join on GT IDs. Retain recovered, lost, persistently unmatched and matched-both GT rows, and report before/after candidate IDs, displacement in native pixels, score change and rank change for matched-both. Candidate slots can switch GT assignments between stages. For the count-side midpoint candidates, retain signed score margin from .30, binary entropy in nats, assigned GT and FP category. Sample the pooled midpoint map in the unique ownership tile at the aligned stride-8 cell for each GT or candidate coordinate after prediction. Use GT only for this analysis.

Tiled synthetic tests cover overlapping ownership on a partial frame, tied-score decode order, original candidate rows and GT matching for every AP threshold, pooled AP, fixed-threshold TP/FP/FN, deployment parity, recovered and persistently unmatched GT, and a matched GT changing slots. The legacy code path keeps identity export disabled. Real-image E40 parity is pending the separate diagnostic.
