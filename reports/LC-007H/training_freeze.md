## Readouts and output schema

Training uses two decoder calls with the existing final loss and .25 midpoint loss. Live and EMA validation each use a single four-stage sweep per epoch. Stages retain the existing count, nAP, grouping and state/update RMS. Every image row stores GT, prediction count, signed and absolute count error, TP, FP and FN. The archiver derives canceled errors as `2 × min(FP, FN)` and reconciles the count identity. The optional candidate-identity path is disabled in this training freeze. No extra validation forward pass is scheduled.

From the same validation activation, log applied gain min/max/mean, population SD, valid token count, changed count/fraction, and aligned/permuted Pearson for the whole sweep and each density stratum. The denominator is all geometrically valid stride-8 cells on every evaluated tile, including each processed copy in overlap. Compare each cell against a permutation within its own tile. Guided arms use the frozen half-roll on the actual map to form the counterpart. In the placebo arm the inverse half-roll recovers the aligned map, and reverse pairing preserves both covariance and the changed count. Pearson is pooled across paired valid cells and undefined when the maps are constant. Empty groups have no gain statistics. These will measure actual trained arms after authorized execution. The E40 control sweep measured hypothetical gains on earlier unguided checkpoints.

The launcher records wall time, exit status, authorization and runner log. The queue writes `preflight_cpu.json`, `queue_progress.json`, GPU phase accounting and memory/background snapshots. Each case writes its run manifest, epoch history, image evidence, checkpoint index and the latest complete checkpoint, with interrupted state when available. The CPU archiver writes compact epoch tables, gain statistics, paired contrasts, the resource and checkpoint index, and the decision, retaining digests for raw artifacts. It can index partial artifacts and leaves joint decisions unevaluable when the frozen queue is incomplete. ## Decision and review

The primary endpoint is E36–40 EMA final, with equal epoch weight per seed and equal seed weight in the macro. Joint gates are evaluated separately for S-guide vs S4-shift, U-guide vs U4-shift, S-guide vs S-placebo, and S-guide vs U-guide. Each requires macro MAE ≤.97× the reference, strictly higher nAP, better MAE and nAP in both seeds, per-seed sample CV ≤10% and absolute relative final-loss change ≤3% (E31–35 to E36–40), and macro RMSE/FP/FN guards of 1.03×/1.05×/1.05×. The matched-baseline comparisons also use the fixed absolute MAE/nAP targets in the execution config. Report the prescribed Shared-2 parity and 3% targets, U2 and U4-shift targets, and the original U4, CNN and Shared-1 comparisons. Report E40, live and density contrasts separately. Shared-2 aux+EMA remains the formal baseline.

The E40 recovery association is descriptive. Midpoint misses below .75 pooled ambiguity account for 62.4% of misses, and all owned midpoint count candidates fell in the highest ambiguity bin. A matched-baseline improvement, placebo improvement, and sharing advantage are distinct findings. Keep the fixed .25 coefficient, half-roll, validation thresholds and readout schedule regardless of outcome. No training or GPU preflight is part of the completed CPU freeze.
