# Related work

Primary-source search on 2026-11-27 covered recurrent refinement, uncertainty-guided dense prediction, confidence-guided attention, crowd point localization and recursive shifted-window sharing. This is a focused comparison of mechanisms. A priority claim would require broader literature coverage and independent empirical evaluation.

| Primary work | Connection to LC-007H |
| --- | --- |
| Carreira et al., CVPR 2016, [Human Pose Estimation with Iterative Error Feedback](https://www.cv-foundation.org/openaccess/content_cvpr_2016/html/Carreira_Human_Pose_Estimation_CVPR_2016_paper.html) | Feeds previous pose estimates back to predict corrections. LC-007H uses a detached midpoint point-logit heuristic to modulate subsequent hidden-state updates. |
| Teed and Deng, ECCV 2020, [RAFT](https://arxiv.org/abs/2003.12039) | Uses a recurrent update operator and correlation lookup for dense optical flow. LC-007H preserves dense shifted-window computation and scales the residual after each late call. |
| Kirillov et al., CVPR 2020, [PointRend](https://openaccess.thecvf.com/content_CVPR_2020/html/Kirillov_PointRend_Image_Segmentation_As_Rendering_CVPR_2020_paper.html) | Uses uncertainty to select points for refinement during segmentation rendering. LC-007H assigns a continuous scale to each valid token and executes every block densely. |
| Wannenwetsch et al., CVPR 2020, [Probabilistic Pixel-Adaptive Refinement Networks](https://openaccess.thecvf.com/content_CVPR_2020/papers/Wannenwetsch_Probabilistic_Pixel-Adaptive_Refinement_Networks_CVPR_2020_paper.pdf) | Uses prediction probabilities and RGB guidance in adaptive convolutions for dense prediction refinement. LC-007H applies centered scalar gain to the full recurrent update while keeping each block operator fixed. |
| Liu et al., ICCV 2021, [Swin Transformer](https://openaccess.thecvf.com/content/ICCV2021/html/Liu_Swin_Transformer_Hierarchical_Vision_Transformer_Using_Shifted_Windows_ICCV_2021_paper.html) | Alternating shifted windows enable cross-window interaction. The window schedule is inherited from LC-007G. Midpoint confidence does not select a window or alter attention weights directly. |
| Song et al., ICCV 2021, [Rethinking Counting and Localization in Crowds](https://arxiv.org/abs/2107.12746) | P2PNet directly predicts crowd points and studies point-level localization. The LC-007H hypothesis concerns update magnitude within a fixed point-decoding pipeline. |
| Chen et al., ECCV 2024, [Improving Point-based Crowd Counting and Localization Based on Auxiliary Point Guidance](https://arxiv.org/abs/2405.10589) | Auxiliary point guidance stabilizes proposal-target matching during training. LC-007H leaves the loss and matcher fixed and derives gain from the model's midpoint logits. |
| Burzio et al., 2026 preprint, [Déjà View: Looping Transformers for Multi-View 3D Reconstruction](https://arxiv.org/html/2605.30215v1) | Repeats a shared transformer block for iterative visual refinement, with time-conditioned residual/state scales and an independent-block comparison. LC-007H tests prediction-dependent spatial residual modulation for crowd points under fixed depth and a gain-permuted placebo. |
| Darko et al., 2026, [U-CFR](https://arxiv.org/abs/2607.20705) | Uses boundary uncertainty to place pseudo-clicks in a cascade for interactive segmentation. LC-007H uses midpoint point scores without external interaction or added heads. |

The scoped hypothesis is that spatially aligned midpoint ambiguity helps the late cross-window recurrent updates correct crowd localization errors. Shared blocks, shifted windows and iterative refinement are established components.
